# Эталонный набор (golden set)

Сюда кладём 20 обезличенных резюме и опросов с картой, которую вручную собрал Никита.
По ним проверяем, что построитель карты не «поехал» после изменений (тест TC-08, спринт 3).

Формат одного случая — `case_XX.json`:

```json
{
  "profession_id": "backend-junior",
  "skills": ["python", "git"],
  "expected_steps": ["sql", "web-framework", "docker", "team-project", "resume"]
}
```

Важно: никаких имён, почты и телефонов. Только навыки.
