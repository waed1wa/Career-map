# Как мы работаем с репозиторием

Договорились на спринте 0, по лекции 12 (Git/GitHub) и лекции 10 (Scrum/Канбан).

## Ветки и пулл-реквесты

1. Одна задача с доски — одна ветка: `feature/<номер>-<коротко>`, например `feature/12-login`.
2. В `main` напрямую не пушим. Только через пулл-реквест.
3. Пулл-реквест смотрит другой участник команды (перекрёстное ревью). Сам себе не одобряешь.
4. Сливаем, только когда CI зелёный: ruff, mypy, pytest, сборка клиента.
5. В описании пулл-реквеста — что сделано и как проверить руками.

## Коммиты

Пишем по-русски, коротко и по делу: `Карта: шаги в порядке изучения`, `Заявки: отказ только с причиной`.

## Когда задача готова (Definition of Done)

- код в `main` через пулл-реквест;
- есть тест на новую логику (для домена — обязательно);
- CI зелёный;
- задача на доске перенесена в «Готово», часы записаны в дневник.

## ИИ-ассистент

- Помогает писать тесты, заглушки, документацию.
- Код от ИИ читаем целиком, прежде чем коммитить. Коммитит всегда человек.
- Бизнес-правила (сроки заявок, отказ с причиной, обезличивание) пишем и проверяем сами.
- Персональные данные пользователей в чат с ИИ не вставляем.

## Доска

Доска в GitHub Projects. Колонки: «Бэклог» → «К выполнению» → «В работе» (не больше 2 задач на человека) → «Ревью» → «Тест» → «Готово».
