# 2026-11-25 · Федотов · Опрос: 6 вопросов вместо резюме

**Зона:** жёлтая (подсчёт навыков по ответам — от него зависит карта студента)
и зелёная (тесты, API).

**Задача.** Неделя 1 плана: API опроса на 6–8 вопросов. Это второй способ войти без резюме —
вывод из CJM (ФП-3): студенты без резюме уходили, когда сервис сразу его просил.

**Что предложил ИИ:**
- спрашивать про то, что студент уже делал руками («делал коммиты в Git»), а не просить оценить
  себя по шкале;
- связать каждый вариант ответа с навыками справочника и проверить тестом, что любой навык
  справочника можно отметить. Иначе знакомый студенту навык навсегда остался бы у него на карте;
- вариант «Пока не знаю» в первом вопросе: тогда профессию выбирает второй вопрос про интересы;
- тесты по классам эквивалентности: по одному тесту на каждый вид неверного ответа.

**Что отклонили или изменили и почему:**
- Таблицу ответов пока не делали: ответы не к кому привязать, пока вход Моисеенко не слит в master.
  Сейчас опрос работает для гостя и сразу показывает навыки — это совпадает с выводом из интервью
  «сначала результат, потом регистрация».
- Предварительную карту прямо в ответе опроса не отдаём: карту строит модуль карты, опрос только
  считает навыки. Так модули не зависят друг от друга лишний раз.
