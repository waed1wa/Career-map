# Журнал работы с ИИ-ассистентом

Правила — в `docs/CONTRIBUTING.md`. Зоны доверия (лекция 12):

| Зона | Что | Как работаем с ИИ |
|---|---|---|
| Зелёная | Тесты, заглушки, документация, конфиги CI | ИИ предлагает, человек читает и принимает |
| Жёлтая | Бизнес-логика модулей | ИИ помогает, обязательно ревью другого участника |
| Красная | Персональные данные, секреты, пять правил системы | Решение и проверку делает человек; ИИ только как подсказка |

Одна запись — один пулл-реквест, где помогал ИИ: отдельный файл `ГГГГ-ММ-ДД-фамилия-задача.md` в этой папке
(отдельные файлы — чтобы записи разных людей не конфликтовали при слиянии). Пулл-реквест помечаем меткой `ai-assisted`.
