# 2026-11-25 · Федотов · Навыки из резюме через LLM и замер точности

**Зона:** красная (текст резюме уходит во внешний сервис — только после обезличивания в шлюзе)
и жёлтая (что из ответа LLM попадёт на карту студента).

**Задача.** Неделя 3 плана: извлечение навыков из резюме через LLM, сопоставление со справочником,
первый замер точности на золотом наборе.

**Что предложил ИИ:**
- в запросе давать LLM весь список навыков справочника и просить ответить только JSON-массивом id;
- ответ LLM не брать на веру: оставлять только id из справочника, остальное отбрасывать и писать
  в лог (Р-3, выдуманные навыки);
- объединять LLM и словарь: словарь находит то, что названо прямо, и показывает, где это написано,
  LLM — то, что сказано своими словами. У навыка есть пометка, кто его нашёл;
- скрипт замера точности и полноты, который заодно считает токены на одно резюме (Р-5).

**Что решили сами и почему:**
- Резюме обрезаем до 6000 знаков: дальше обычно хобби, а токены платные.
- В запросе прямо просим не засчитывать «не работал с …» и «хочу изучить» — словарь так не умеет.
- Порог «точность не ниже 80%» взяли из плана (риск Р-6). Скрипт падает ниже порога, чтобы мы это
  не пропустили.
- Поиск похожих навыков через pgvector пока не делали: нужны эмбеддинги и таблицы в базе, а база
  справочника по плану — неделя 4. Синонимы в справочнике пока закрывают эту задачу.
- Один тест поменяли после реализации: массив внутри объекта `{"skills": [...]}` теперь принимаем.
  LLM часто так отвечает, а сверка со справочником всё равно защищает.

**Что проверил человек (без этого не сливаем):**
- [ ] Прочитал запрос в `llm_skills.py`: понятен ли он и нет ли в нём лишнего
- [ ] С ключом GigaChat прогнал `python -m app.tools.eval_golden_set --llm` и записал точность, полноту и токены в дневник
- [ ] Сравнил с запуском без `--llm`: LLM действительно что-то добавляет
- [ ] `ruff check .`, `mypy`, `pytest` — зелёные в CI

**Известные ограничения:** настоящий замер точности невозможен, пока в золотом наборе нет резюме.
Скрипт готов, данные — за командой.
